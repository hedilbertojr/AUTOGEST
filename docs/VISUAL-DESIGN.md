# Identidade visual

Ícones vetoriais da biblioteca Lucide, versão 1.73.0, usados no menu, botões, marca e indicadores. Licença preservada em `frontend/assets/licenses/lucide.txt`.

Fonte Inter Variable, versão 5.3.0, distribuída por Fontsource e carregada localmente em WOFF2. Licença preservada em `frontend/assets/licenses/inter.txt`.

A interface usa uma paleta grafite/verde-petróleo, controles com rótulos, foco de teclado visível, SVGs decorativos escondidos de leitores de tela e tabelas com rolagem própria em telas pequenas. O build mantém arquivos versionados e todos os recursos visuais locais.

Fontes e licenças:

- https://lucide.dev/license
- https://fontsource.org/fonts/inter
